| **2 — P1** | Исправлен в конфигурации | CD закрепляет заранее проверенный SSH host key, включает строгую проверку и останавливается при отсутствии ключа. Применение настроек на GitHub и выполнение CD этой сводкой не подтверждаются. |
| **3 — P2** | Исправлен | Login/refresh ограничивают всё тело 4096 байт до JSON-декодирования и длины полей до операций с credentials. |

| **5 — P2** | Исправлен | Web Locks сериализуют refresh между вкладками; проверены обе ведущие вкладки, logout и смена аккаунта. |

Исправление №6 ограничивает размер страницы; большой offset всё ещё может быть дорогим. Этот остаточный аспект описан в отчёте P2 и не объявляется новым подтверждённым замечанием без отдельной проверки последствий.

## Замечания вне исходной таблицы

GO-2026-6443 (gRPC 1.83.1, условие xDS в текущем сервере отсутствует) и GO-2026-6809 (crypto/x509 в Go 1.27.2, сканер указывает исправление в Go 1.27.3) не входили в исходные 11 пунктов. Они есть и в исходном HEAD, и после исправлений P3. Динамическая эксплуатация на проекте не воспроизводилась; это отдельные задачи обслуживания зависимостей/toolchain. Их нельзя считать устранёнными или включать в число исправленных исходных пунктов. Подробности — в аудите зависимостей [отчёта P3](SECURITY-P3-FIXES-2026-10-21.md).

## Метод и границы обновления

- Для P3 выполнены целевые регрессионные проверки после каждого исправления, затем общий backend-набор с PostgreSQL и race detector, отдельные Go-модули и контейнерные тесты выпуска. Результаты и методика зафиксированы в отчёте P3.
- Зависимости просканированы на рабочей копии и отдельном архиве исходного HEAD: новых symbol-level ID — 0; результат сканирования не чистый из-за двух перечисленных предупреждений.
- Изменения ещё не означают выпуск в production. Деплой, реальные платежи и отправка писем не выполнялись.
- Сводка описывает судьбу исходных 11 пунктов, а не результат полного поиска всех возможных уязвимостей проекта.
