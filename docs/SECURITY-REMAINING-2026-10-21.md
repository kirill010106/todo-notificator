## Что исключено из открытого списка

| Исходный № | Состояние в рабочей копии | Основание |
|---|---|---|
| **1 — P1** | Исправлен | Refresh-секрет хранится и ищется по SHA-256; миграция 00026 отзывает старые refresh-сессии. Проверки и ограничения выпуска — в отчёте P1, повторная PostgreSQL-интеграция — в отчёте P2. |
| **2 — P1** | Исправлен в конфигурации | CD закрепляет заранее проверенный SSH host key, включает строгую проверку и останавливается при отсутствии ключа. Применение настроек на GitHub и выполнение CD этой сводкой не подтверждаются. |
| **3 — P2** | Исправлен | Login/refresh ограничивают всё тело 4096 байт до JSON-декодирования и длины полей до операций с credentials. |
| **4** | Исключён при перепроверке | Подключённая публичная регистрация использует атомарный `account.Handler.Register` → `RegisterAccount`; дефект старого неподключённого обработчика не переносится на рабочий маршрут. |
| **5 — P2** | Исправлен | Web Locks сериализуют refresh между вкладками; проверены обе ведущие вкладки, logout и смена аккаунта. |
| **6 — P2** | Исправлен | История ограничена 100 записями на HTTP/gRPC-уровнях и 4 МиБ сериализованного protobuf-ответа; Free сохраняет предел 5. |
| **7 — P2** | Исправлен | Ошибки Decode и cursor.Err завершают запрос ошибкой без успешного частичного результата. |
| **11 — P2** | Исправлен | Оба финальных webhook сверяются с API провайдера; SQL запрещает смену одного финального статуса на другой. Проверены повторы, конкуренция и откат выдачи Premium. |

Исправление №6 ограничивает размер страницы; большой offset всё ещё может быть дорогим. Этот остаточный аспект описан в отчёте P2 и не объявляется новым подтверждённым замечанием без отдельной проверки последствий.

Предупреждение gRPC `GO-2026-6443` не входило в исходную таблицу, поэтому здесь не получает нового номера и не прибавляется к трём открытым пунктам. Его условность и плановое обновление зависимости разобраны в разделе аудита Go-зависимостей [отчёта P2](SECURITY-P2-FIXES-2026-10-21.md).
